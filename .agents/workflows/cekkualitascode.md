Evaluate Code Quality
Evaluation Criteria
Evaluate the code and give a score from 0-10 for each section:

Functionality: Does the code correctly solve the task and handle main states?
Code Clarity: Is the code easy to read and understand?
Structure: Is the code organized well and aligned with project patterns?
Code Duplication: Is repeated logic or UI avoided?
Performance: Are obvious performance issues avoided?
Accessibility: Are there any visible accessibility problems?
Tests Coverage: Are important scenarios covered by tests?
Maintainability: Will this code be easy to change later?
Output Format
For each section, write a short comment what is good and what should improve, and give a score in this format: X/10.
At the end, provide the overall score in this format: X/10 with a brief summary.
Suggest the top 3 critical fixes first.
